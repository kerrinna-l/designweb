# Portfólio Pessoal - Tailwind CSS

Portfólio pessoal desenvolvido com Tailwind CSS.

## Tecnologias Utilizadas

- HTML5
- Tailwind CSS (via CDN)
- Font Awesome Icons
- Google Fonts (Raleway + IBM Plex Mono)

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Não é necessário instalar dependências - tudo via CDN

## Estrutura

- `index.html` - Página principal
- `assets/img/` - Imagens e logos

## Características

- Design responsivo
- Cores personalizadas
- Animações suaves
- Layout moderno e limpo
